## DeFi Investment Calculator Overview

DeFi Investment Calculator provides an in-browser way to explore potential outcomes for decentralized finance positions. Its calculations cover common planning cases, including liquidity pool returns, trading fees, impermanent loss, and the effect of different compounding schedules.

Crypto users can use the calculator to test assumptions and review possible results before allocating funds. Since it works in the browser and preserves entered values in the browser's local cache, recurring analysis can be performed without entering the same information each time.
